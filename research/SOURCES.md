# PANORAMA SE 360 屏幕与 KANALI 来源核查

核查日期：2026-11-02。对象仅为 **TRYX PANORAMA SE 360 ARGB**；不将普通 PANORAMA、PANORAMA WB、STAGE 或 SE V2 的几何参数代入本项目。网页规格会更新，以下结论保留了核查日期及本地证据。

## 1. 官方已确认的参数

主要来源：[TRYX PANORAMA SE 360 ARGB 官方产品页](https://www.tryx.com/en/products/cooling/panorama/panorama-se/black-360)。已实际读取网页及其 HTML 内的结构化页面内容。

| 项目 | 官方内容 | 对本项目的意义 |
| --- | --- | --- |
| 面板类型 | AMOLED 曲面屏 | 是连续弯曲屏幕，圆角区域需要考虑 |
| 分辨率 | **2240 × 1080** | 优先采用此原生输出画布；并非精确 2:1，而是约 2.074:1 |
| 刷新率 | **60 Hz** | 这是面板刷新率，不等于已证明所有编码的 60 fps 视频都能导入和播放 |
| 屏幕对角线 | **6.67 英寸** | 不能单独确定发光面宽高和折角半径 |
| 可视面积口径 | **6.5 英寸 visible area** | 官网未进一步定义展开对角线、遮罩裁切和弯曲段的测量方式 |
| 亮度 | 400 cd/m² | 不影响几何映射 |
| 像素密度宣传图 | 372 PPI | 可作数量级交叉检查，不能取代发光面实测 |
| Screen Rotation | 90° / 180°，3 种调整角度、12 种安装组合 | 指显示模块方向/安装旋转，**不能据此证明屏幕左右两面恰好夹角 90°** |
| Pump Size | 125 × 94 × 92 mm | 是泵头总成外廓，不是有效屏幕展开尺寸 |
| G2 Curvature Design | 官方描述强调平滑连续的曲率过渡 | 未给出毫米半径、圆弧长度、曲率函数、顶点数据或两端切线角 |

当前官方页面清楚标为 2240 × 1080。网上部分经销商/旧教程仍写 2160 × 1080 或直接把 6.5 英寸当面板总尺寸；这些不能优先于当前型号的官方规格。也不能只根据分辨率，假定 KANALI 的裁切步骤会保持全部 2240 列像素：实际导入时需要用边框/网格测试观察裁切。

官方安装说明：[PANORAMA SE User Manual（20260330）](https://upload.tryxzone.com/products/manual_PANORAMA_SE.pdf)。此文件是安装与接线折页，未提供上述缺失的光学/几何标定数据。

## 2. 推算尺寸：仅用于初始模型

以下**不是厂家公布的有效发光面尺寸**。假设展开后是矩形、像素等距、分辨率比例等于物理宽高比，可按 `r = 2240/1080`、`H = 25.4D/sqrt(1+r²)`、`W = rH` 推算：

| 采用的对角线 D | 推算展开宽 W | 推算高 H | 适用边界 |
| --- | --- | --- | --- |
| 6.67 英寸 | 152.606 mm | 73.578 mm | 面板名义对角线假设 |
| 6.5 英寸 | 148.717 mm | 71.703 mm | 假设“可视面积”也能当同一宽高比矩形的对角线；官方未确认这个假设 |

从 372 PPI 反算得到约 152.946 × 73.742 mm，与名义 6.67 英寸数量级接近；因 PPI/对角线均有取整，不能把该推算解释成精密测量。应让模型的展开宽、高、左右直段、过渡宽度及夹角可调。直角折屏和圆弧过渡只能作为近似，不可声称复现了真实 G2 轮廓。

即使所有物理尺寸统一缩放，只要观察点距离也同比缩放，投影结果不变；实际有效宽高、弯曲轮廓及观察点相对位置仍决定校正结果。

## 3. KANALI 导入规格与功能边界

主要来源：[TRYX KANALI 官方页面](https://www.tryx.com/en/kanali)。页面的 “Easy Upload, Broad Compatibility” 明确说明：

- 支持 **PNG、JPG、MP4、AVI、GIF**。
- **每文件最大 500 MB**。
- 可上传个人照片/视频，提供预设内容、滤镜、CPU/GPU 标签等功能。

官方 SE 产品页另说明 KANALI 有预制的官方 3D 格式内容库、自定义内容库和左右分屏。它没有承诺把任意普通视频按任意用户观察点自动计算透视反变形。因此，本项目自行生成校正视频是独立的离线处理流程，不能把官方“3D 内容库”描述成通用的自动 3D 映射功能。

| 参数 | 本次官方核查结果 |
| --- | --- |
| 视频容器 | MP4、AVI 已公开 |
| 每文件体积 | 500 MB 已公开；MB 的十进制/二进制口径未定义，输出宜留余量 |
| 视频编码 | 未找到 H.264/H.265/AV1 等完整兼容清单 |
| H.264 profile / level / 色度 | 未公开 |
| 导入/播放帧率上限 | 未公开；60 Hz 面板不是视频导入兼容性证明 |
| 码率上限 | 未公开 |
| 时长上限 | 未公开 |
| 当前版本分辨率硬上限 | 当前主站文字未明确给出 |
| 任意观察点的投影/反变形 | 未找到官方支持说明 |

当前官方导航数据列出 KANALI v2.6.0，下载文件名日期为 2026-10-08；本次未安装或运行它，不能据此宣称已完成 KANALI 实机测试。

作为兼容性起点，可选 MP4 + H.264 + yuv420p、30 fps、无音轨、远低于 500 MB。**这是保守的工程选择，不是厂家已认证的唯一格式或硬上限**。若需 60 fps，应先上传短测试片验证。

旧销售资料及 [MAINGEAR 的 SE 产品介绍](https://maingear.com/blogs/promotions/tryx-panorama-se-cooler-now-available) 写有 1080p / 500 MB，但后者是整机合作方而非 TRYX 软件规格本体，且当前 TRYX 主站没有复述 1080p 限制。因此不将“1080p 上限”当作当前所有版本的确定硬限制，也不据此把 2240 × 1080 改为 1920 × 1080。
