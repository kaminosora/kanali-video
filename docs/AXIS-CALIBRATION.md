# 弯折中轴错位测试与校准

这项测试模拟：**按 A 中轴生成的预变形画面，播放到中轴实际位于 B 的屏幕上**。
弯折中轴按展开视频从左向右的位置表示，50% 对应 2160 像素画布上的 x=1080。
它不是素材取景的左右平移，也不是观察角度。

## 为何可能出现 S 形直线

若预变形所用弯折位置与实际弯折不一致，相同的一列像素会落到不同的曲面法线和
空间位置上。原来用于抵消曲面的变形便会在过渡区留下局部伸缩、弯曲或 S 形残差。
观察者略高于屏幕时，多条水平线特别适合看出这种误差；偏移方向相反时，残差方向
也会变化。具体形状还受眼位、距离、弧长和总弯折角影响，并非所有 S 形都由中轴造成。

## 推荐操作

1. 先关闭亮度补偿和角度亮度模拟，固定实际观看位置。确认 KANALI 使用完整 2:1
   画面，没有额外裁切、缩放、旋转或平移。设置接近真实情况的眼位与屏幕尺寸。
2. 展开“实验：弯折中轴错位”，载入平行线测试图，使用铺满模式。图中有多条水平线、
   竖线、斜线和左右标记，便于比较方向。中间青色线只是原片 x=1080 参考线，
   不应把它当成物理弯折的位置标记。
3. **渲染假设轴必须等于你正在比较的成片生成时的设置。** 尚未校准的默认输出为
   50%。先用该值导出测试图并放到屏幕上，随后点击“以当前渲染轴开始测试”。
4. 开启错位模拟，保持渲染轴不变，只调“模拟实际轴”，让电脑上的观察预览尽量重现
   实屏的弯曲位置、方向和幅度。图像展开预览不随这个滑条变化；它仍是当前成片内容。
5. 匹配后，界面会给出中轴位置与像素差值。点击“应用实际轴到渲染”，程序将该估计值
   写入正式 `bend_center_u`，并重置取景。此时两轴一致，模拟中的直线应恢复。
6. 重新导出、上屏复查，再保存预设。若仍有残差，分别检查眼位、弧长与弯折角；不要
   同时调整多个变量。几何接近后，再用中灰图调整[角度亮度补偿](BRIGHTNESS.md)。

假设默认成片使用 50%，你将模拟实际轴调到 52% 后重现了实屏弯曲：
差值为 +2 个百分点，即 +43.2 个输出像素；建议正式渲染轴为 52%（x=1123.2）。
程序会应用这个连续坐标，最终以正常像素采样输出，不需要把偏移取整为像素。

## 这不是自动测量

两个滑条都能调是为了比较假设，不表示可以唯一解出实体结构。若同时自由移动两轴、
又调整眼位和弧长，不同组合可能给出相似误差。只有把被比较成片的渲染轴固定下来，
再用真实屏幕的观察结果约束模拟实际轴，得到的建议位置才有明确的校准意义。
“应用”是把人工匹配后的物理假设转换成正式渲染设置；程序没有摄像头输入，也未做
图像测量或光学标定，不保证一次拟合就等于真实硬件尺寸。

## 数据与模型边界

- `bend_center_u` 是正式设置，写入预设、GPU/Blender 导出和工程文件；默认 0.5。
- 模拟开关和模拟实际轴只存在当前网页，不写入预设或导出。只有点击应用才会改变
  正式渲染轴。保存预设前检查正式轴数值。
- 观察预览保留渲染模型计算的源 UV 和亮度增益，在相同展开 UV 上替换成实际假设
  屏幕的位置、轮廓和角度响应。这不是移动图片的近似。
- 眼位相对物理弯折中心定义；调中轴改变左右有效屏幕长度，物理弯折中心仍为世界原点。
- 当前仍是 G2 对称过渡曲线；中轴校准不会自动求出厂家真实曲率分布、非均匀像素节距
  或面板边缘裁切。完整过渡必须落在屏幕内，界面会限制有效范围。
- 平屏（弯折角 0°）没有弯折中轴误差，调整该参数不会改变几何。
- 输出始终为 2160×1080、SAR 1:1；MP4 仍执行严格小于 500,000,000 字节的检查。
