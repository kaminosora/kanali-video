# PANORAMA SE 实机视点与曲面校准

本流程的目标是：**在固定观察位置，把保留的视频区域看成一个平面**。先确认方向和播放映射，再调眼位与屏幕形状，最后用实际视频复验。每次只改一类参数，保存能复现的记录。

默认 45° / 10° / 650 mm、90°弯折和 14 mm G2 过渡只用于开始试验。官方面板规格标称 2240×1080、60 Hz，但这不等于 KANALI 的上传画布。用户实测上传窗口为 2:1，v1.1.1 起统一导出 **2160×1080、SAR 1:1**。厂家没有提供可直接代入的精确有效宽高与 G2 曲率函数，详情见 [来源记录](../research/SOURCES.md)。上传像素比例的修正不自动改变已有的毫米尺寸和眼位。

## 1. 固定屏幕与观察位置

1. 固定机箱位置、桌面高度和屏幕安装方向。校准过程中不要移动机箱或改变水冷屏幕的安装角度。
2. 选一个日常最重要的观看位置，例如坐在椅子上正常看机箱的位置。此位置是效果优先的设计眼位。
3. 用三脚架或稳定支撑把手机**后置主摄镜头的中心**放到这个眼位；测量点是实际镜头，不是手机机身中心。主摄常规视角即可，避免超广角和随录制自动切换镜头。
4. 镜头对准屏幕弯曲中心、半高处。把屏幕放在照片中央，固定焦距、机位和取景；在条件允许时锁定曝光与焦点，让每轮照片可比。
5. 用桌沿、胶带标记或支架刻度记录机箱、镜头和椅子的位置。单眼/单镜头是明确的投影基准；双眼观看是这一单视点效果的折衷，不能让两个眼位同时完全满足同一映射。

建议记录：手机/相机型号、使用镜头、屏幕安装方向、观看水平角、俯视角、距离、镜头相对屏幕中心的高度差，以及本轮 KANALI 的屏幕方向和播放设置。

## 2. 测量眼位，理解三个参数

| 控件 | 实际含义 | 如何取得初值 |
| --- | --- | --- |
| 水平角度 | 45°为左右两翼平分方向 | 从上方观察屏幕两翼与镜头的位置，先判断是否对称，再据实际位置调整 |
| 俯视角度 | 镜头高于屏幕中心时为正 | 测镜头与屏幕半高中心的高度差、水平距离 |
| 观看距离 | 镜头到屏幕弯曲中心、半高点的直线距离 | 测真实斜距，而不是只量桌面上的水平距离 |

如果镜头高于中心 `h` mm、水平距离为 `r` mm，可以估计：

```text
俯视角 = atan(h / r)
观看距离 = sqrt(h² + r²)
```

默认距离 650 mm、俯视 10°对应高度差约 113 mm、水平距离约 640 mm。它仅解释参数，不要求把你的机位强行摆成这个数值。`水平 45°` 也不是“相对机箱玻璃一定为 45°”；实际参照是屏幕两翼。

在工作台“观察位置”输入实测值。先保持曲面默认值，避免同时用曲率去补偿眼位误差。界面若拒绝某个视点，表示该模型下不能同时看到需要的屏幕正面，不能继续用该配置得出可靠校正。

## 3. 先确认方向与 KANALI 映射

1. 打开工作台，点击 **载入方向校准网格**。
2. 点击 **立牌小屏**，保持切入后的默认取景；此时整幅网格及装饰应在目标视点预览中完整出现。
3. 导出 3–5 秒短 MP4。快速试验可用 1×；最终复验用 2×。选择 30 fps 即可检查静态网格。
4. 在 KANALI 选择整块屏幕的单画布/全屏显示，关闭左右分屏，导入这段文件。
5. 关闭会遮住或改变内容的系统信息、CPU/GPU 标签、滤镜等叠加。避免额外的缩放、平移或手工裁切；若软件弹出裁切界面，检查其 2:1 窗口是否保留了全部 **2160×1080** 画面。
6. 从固定手机镜头位置观察：红色 TOP LEFT、绿色 TOP RIGHT、蓝色 BOTTOM LEFT、黄色 BOTTOM RIGHT 是否对应正确方向；文字是否正立，左右是否交换。
7. 若方向错误，先统一设备安装方向、KANALI 屏幕旋转与本项目横向画布的关系，再进行后续校准。调整播放方向后，重新确认四角和左右两翼。

KANALI 不同版本的按钮名称和导入裁切行为可能变化。这里的原则是保留已生成的单画布映射；不能因为软件显示“全屏”就假定它没有重新裁切。若软件只能采用不同宽高比的裁切，先记录这个事实并停下几何调节，否则会把播放软件的缩放误当作屏幕曲率。

旧版 2240×1080 展开成片不能直接居中裁成 2:1，因为被裁掉的两端仍属于完整曲面 UV 映射。优先以原素材和原校准参数在新版重新导出；仅有旧成片时，应将整幅图缩放到 2160×1080 并设 SAR 1:1，再检查体积与四角。不要重复对已经预变形的成片做曲面映射。

此步骤中完整四角是检查内容是否被意外裁掉的依据。切换回“铺满取景”后，原片部分边缘被主动裁切是预期行为，不能再要求它保留所有四角标签。

## 4. 在固定机位观察圆与直线

先让方向正确的网格循环播放，用同一机位拍一张清楚照片。观察顺序：

1. **完整圆**：选取至少一个完全保留在可见区域中的圆，比较水平和竖直直径。不要用被裁掉一部分的圆判断宽高比。
2. **横线**：选择穿过左右两翼及中间过渡的同一条横线，看它是否在照片中连贯成直线。
3. **竖线**：比较中心附近及左右区域的竖线是否出现弯曲、倾斜或局部疏密突变。
4. **空间一致性**：比较左、中、右的圆和网格格距，判断问题是全局比例、左右不对称，还是仅集中在折弯附近。

预期是被保留的源网格像一张平面图，而不是要求实体屏幕的外轮廓变成矩形。实际曲面外形、铺满裁切轮廓和视频内容的投影是不同对象。

工作台的“目标视点效果 → 已校正”是模型内的预测；实体屏幕的照片才用于判断模型与实物是否吻合。“曲面展开图”里的弯曲和拉伸是补偿量，不要为了让展开图本身看着方正而修改校准。

## 5. 一次只调一类参数

先保存初始预设，例如 `calib_A0_measured_eye`，并把对应照片命名为同样前缀。每次改动后生成新的短片，记录旧值、新值和对应任务目录；保持手机、屏幕及 KANALI 设置不变。

| 观察到的现象 | 优先检查 | 单次比较方式 |
| --- | --- | --- |
| 左侧正常、右侧明显挤压，或两边比例不对称 | 镜头水平位置、水平角度是否一致 | 固定曲面，水平角每次改约 0.5–1°，比较同一组左右网格 |
| 上下比例不同、横线整体向一侧倾或呈梯形变化 | 镜头高度、俯视角、镜头是否对准中心 | 先重测机位，再以约 0.5–1°比较俯视角 |
| 圆整体偏扁/偏长，但左右比较一致 | KANALI 缩放、屏幕有效宽高比、距离测量 | 先排除二次裁切；再按实测有效尺寸调整比例 |
| 左右直段大致正确，中间弯区仍鼓起/收缩 | 两翼弯折角、G2 过渡弧长 | 先改弯折角约 1–2°，保留更好者；随后弧长每次改约 0.5–1 mm |
| 靠近中缝出现局部拉伸，远离中缝变化很小 | 过渡段形状与长度假设 | 固定眼位与弯角，对比 12、14、16 mm 等邻近候选，再缩小步长 |
| 手机轻微前后移动，整体效果明显变化 | 观看距离是否是真实斜距 | 回到标记位置，重测距离；以约 10–20 mm 比较候选 |

这些是定位顺序，不是“某现象一定只对应某参数”。多个误差可能相互补偿，所以优先测量眼位；不要只凭一张照片同时改变五个参数。

有效高度应指实际显示内容的高度。展开宽度是沿屏面的长度，不是屏幕两端之间的直线距离，也不是泵头外壳的宽度。若无法可靠测量，保留当前尺寸假设并明确记录；不能把 125×94×92 mm 的泵头总成尺寸填成发光面尺寸。

本模型的过渡段满足 G2 连续：与直翼接合处切向和曲率连续。**14 mm 是这段过渡的弧长，不是半径**。它没有厂家公开的精确轮廓保证；如果反复微调后只能改善部分区域，应记录残余误差，不必通过极端数值把别处拉坏。

每轮都回看保留下来的圆、穿过中缝的横线以及两侧网格，避免只改善中心一个点。找到较好组合后，在不同时间重新坐回该眼位复查，再保存稳定预设。

## 6. 分别验收铺满与完整立牌

### 铺满取景：最终常用的大视频模式

1. 切到 **铺满取景**。模式切换会把缩放恢复为 1×、平移归零，保留曲面与眼位。
2. 在大原片上拖动可见区域轮廓；暗区不进入成片。需要更自由的上下/左右移动时，先略微放大。
3. 自动限位只保证采样不越过原片边界。源视频已经编码进去的黑条、字幕背景或黑色场景不会被自动删除。
4. 选择关键主体，让脸、文字、窗口框等至少在一个重要时间段完整处于保留区域。它们跨过弯区时应保持同一平面内的形状。
5. 检查四周是否存在非预期的画面外黑缝，同时接受由你选定的裁切造成的内容损失。不要用“完整立牌”的小矩形效果替代这一步。

### 立牌小屏：保留完整视频的辅助模式

1. 点击 **立牌小屏**，或点击 **重置取景**，保持默认缩放和平移。
2. 从设计眼位检查整段视频的四角、边框、厚度感和底座均在屏幕内；视频应像一块完整的平面小屏幕。
3. 如果继续放大或平移，完整性就变成你的主动构图选择，可能裁掉部分视频或装饰；需要完整画面时再次重置取景。
4. 装饰的厚度感与底座是平面图像产生的单视点 2.5D 视觉效果。它不重建视频里的真实三维场景，也不为两只眼分别生成画面。

“未校正”对照只展示普通视频在曲面上的形变，不包含立牌装饰，因此不要把装饰有无作为几何是否正确的判断依据。

## 7. 用实际视频的地标和时间节点复验

网格正确之后，载入真正要播放的视频。选择含清楚形状的片段：圆形表盘、正面的矩形标牌、建筑窗框、角色脸部或稳定的字幕框都可以。尽量同时包括靠左、过中缝和靠右的特征，而不是只看中心脸部。

建议为这段片子记录五个时间节点，例如片段开头、约 25%、50%、75% 和结束前最后一个可见画面。每个时间点写下：主体、要保留的边缘、预期是圆/直线/矩形的地标。需要定位具体帧时，使用同一时间戳的原片暂停截图作参考。

按最终模式和取景导出一段 3–10 秒短片，再在 KANALI 播放并从固定眼位拍摄。对照原片及“目标视点效果”检查：

- 人物或物体经过中间弯区时，局部宽高比是否连续。
- 同一个矩形的上边、下边和竖边是否同时合理，而不是只校准一个角。
- 保留区域内不同地点是否共同构成平面；立牌模式能否看到完整视频边界。
- 入点处是否显示当时正在播放的画面，VFR 停留段是否保持，尾帧是否存在，循环首尾是否符合你的素材设计。

只看 `first-frame.png` 不能验证运动或时间连续性。工作台视频代理最多 30 fps，也不能替代最终文件的帧率检查。正式导出保留源帧率，最高 60 fps；不要为“整数好看”把 29.97 手动改成 30。

## 8. 保存、正式导出与 KANALI 验收

1. 保存最终眼位/几何预设，名称写清安装位置或观看位置。另为不同视频保存构图预设，避免覆盖唯一的校准基线。
2. 正式导出推荐 **高质量 MP4 / 自动体积控制 + 2×超采样**，确认交付尺寸为 **2160×1080 / 2:1**。无损 RGB 母版用于留档，需要设备播放时仍导出 MP4。
3. 查看成片体积；工作台按实际字节数确保 MP4 严格小于 **500,000,000 字节**，超限时自动重编码。若预算压缩后细节不足，可缩短片段。不能假定当前 KANALI 一定接受所有编码或帧率组合，应先用短片实际导入。
4. 导入时再次确认单画布、方向、缩放/裁切及叠加设置与校准一致；更换 KANALI 版本或屏幕旋转设置后重新执行方向和四角检查。
5. 保留任务完整文件夹，特别是 `work/source.mkv`，以及 `panorama.blend`、`render-settings.json`、日志与校准照片。不要把任务 `work` 当可随意删除的下载缓存。

最后分别从设计眼位与偏离位置看一次：设计眼位优先满足平面效果，偏离位置出现形变是该方法的限制。机箱位置、椅子高度、屏幕方向或常用观看点改变后，应使用新的预设重新校准。
