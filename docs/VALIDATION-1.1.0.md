# v1.1.0 发布验收

日期：2026-11-03。环境：Windows x64、Python 3.13、Blender 4.5.4 LTS、RTX 5080；同机有 AMD 集成显卡。这里只记录可复现的软件验证，未把模型预览等同于实体屏幕/KANALI 校准。

## 自动化回归

- `python -m unittest discover -s tests`：125 项通过。
- `node --test web/*.test.cjs`：3 套通过，涵盖取景坐标、断线轮询恢复、渲染选项、估算防抖和加速回退。
- `python scripts/test_release.py`：13 项通过，含发布白名单、固定 ZIP 排序、私有路径拒绝、许可证代码缓存排除、冻结代码与 EXE 一致性、下载 SHA-256 校验失败清理、ZIP 路径逃逸拒绝、拒绝下载/已有版本/安装成功状态。
- 尺寸测试覆盖等于限制时拒绝、有限次数重试、真实两遍 x264 压缩、取消、候选保留和最终文件原子发布。小预算测试不需要生成数百 MB 测试文件。
- 取消测试覆盖完成提交竞态、阻塞的 rawvideo 编码管道、渲染子进程不响应时超时清理。驱动探测原生崩溃或超时后，独立试编码 CPU x264，主服务不加载故障 GL 驱动。
- 软件 OpenGL 被拒绝为“硬件加速”。NVIDIA/AMD/Intel vendor 中立接口有模拟测试，不能替代对应硬件实测。
- 深中文空格路径复查曾复现 x264 `can't open stats file`。Windows 扩展绝对路径修复后，在目录本身超过 270 字符的条件下，默认执行器和任务执行器均完成真实两遍编码，60 帧且小于 35,000 字节测试上限。

## 真实渲染

运行本地服务后执行 `python scripts/verify_pipeline.py --mode all`。这些示例均由程序生成的网格或 FFmpeg testsrc2 制作，无用户媒体内容。

| 场景 | 路径 | 帧数 / 帧率 | 输出 |
| --- | --- | --- | --- |
| 铺满网格 | GPU + NVENC，2× | 90 / 30 fps | 351,427 字节 MP4 |
| 完整立牌 | GPU + NVENC，2× | 90 / 30 fps | 375,797 字节 MP4 |
| 动态测试 | GPU + NVENC，2× | 18 / 30000/1001 fps | 2,157,269 字节 MP4 |
| 归档母版 | Blender + FFV1 | 6 / 60 fps | 9,779,311 字节 MKV、gbrp16le |
| 取消任务 | 自动加速 | 取消后无成功成片 | 通过 |

MP4 解码检查为 2240×1080、H.264、yuv420p、BT.709；帧数和时间戳递增符合设定。动态首尾像素平均差 4.015/255，排除视频贴图冻结。GPU 与 Blender 的合成图颜色/几何对照见 [硬件说明](HARDWARE.md)。

## 界面与便携运行

浏览器实测导出选项与实际 GPU 检测；60 秒/30 fps 预算显示 1800 帧和 63.87 Mbps，修改区间后自动更新。立牌保留完整网格及边框底座。

首轮便携包移至中文、空格目录，从其他工作目录运行，子进程 PATH 移除系统 Python。首次通过官方 PyPI 安装 PyAV 16.0.1，校验 SHA-256；手动保存 Blender/FFmpeg，分别完成 GPU+NVENC 和 Blender+x264 的 6 帧成片。设置、缓存、输出均位于移动后的包目录。该验证模拟无 Python 使用条件，并非一台独立干净 Windows 虚拟机。

最终冻结后，从正式 ZIP 解压到另一中文空格目录，重复上述首次下载与无系统 Python PATH 验收通过：GPU+NVENC 输出 283,159 字节，Blender+x264 输出 148,504 字节，均为 6 帧且保存有效 Blender 工程。发布说明更新后的归档再校验全部运行文件散列与这一实测包一致。

最终便携包另通过真实视频解码/GPU 映射：NVENC 成片 556,177 字节、AMF 成片 364,094 字节，均 6 帧。这里 AMF 使用本机 AMD 集成显卡编码，OpenGL 映射仍在 NVIDIA 上，不能推断纯 AMD 机器表现。最终源码 ZIP 解压到深中文空格路径后，125 项测试全部通过。

发布包不含个人路径、设置、素材或日志，不含 Blender/FFmpeg/PyAV 原生媒体库。首次下载的媒体库直接来自上游；其后可离线运行。

## 实际超限文件验证

以一段已经完成映射的本地视频进行实际大小约束验证：候选 **530,263,201 字节**，经过一轮两遍 x264 自动预算编码，交付 **478,344,474 字节**（严格小于 500,000,000）。耗时约 236 秒，无需重跑 Blender；原候选保留。完整解码核对 12,426 帧、2240×1080、递增时间戳。该私有视频及其路径、截图、日志均不随发布分发。

## 验收边界

Intel QSV、AMD 独立显卡及 AMD/Intel OpenGL 整条路径未实机验证。本机 AMD 集成显卡的 AMF 两帧实际编码探测通过。非 Windows、旧驱动、远程桌面和虚拟机尚无完整验收。KANALI 的实际导入和实体屏幕观感仍需用户按 [校准指南](CALIBRATION.md) 确认。
